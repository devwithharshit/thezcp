# The Zero Credit Project — Restored Old Site Design

This version recreates the older TZCP storefront design from the supplied reference screenshot: white minimal header, centered original mark, five-panel dark editorial hero, pagination dots, and the original quiet-drop newsletter/footer.

The five hero panels were cropped directly from the supplied old-site reference so the visual arrangement and copy match the reference.

Pages included:
- `index.html` — restored old homepage/hero
- `collections.html` — shop grid in the same visual language
- `product.html` — product detail template
- `contact.html` — contact page
- `assets/` — restored hero crops, logo and product imagery
- `reference-home.png` — supplied visual reference used for restoration

Open `index.html` locally to preview.
